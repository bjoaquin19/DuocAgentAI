================================================== REGLAS DE INTERPRETACIÓN PARA EL AGENTE ==================================================

1. Todas las fechas corresponden al Calendario Académico Duoc UC 2026.

2. Diferenciar siempre entre:

- Temporada Académica de Verano (TAV).

- Primer semestre 2026 (2026-1).

- Segundo semestre 2026 (2026-2).

3. Cuando el usuario pregunte por una fecha, responder utilizando

exclusivamente las fechas indicadas en este calendario.

4. Si un evento tiene fecha de inicio y término, indicar ambas fechas.

5. Si se trata de un evento de un solo día, indicar únicamente esa fecha.

6. Si el usuario pregunta cuánto falta para un evento, utilizar la fecha

correspondiente del calendario y compararla con la fecha actual.

7. Si el usuario pregunta si un proceso se encuentra vigente, comparar

la fecha actual con las fechas de inicio y término.

8. No inventar fechas que no estén presentes en esta fuente.

9. Si la información solicitada no aparece en este calendario, indicar

que el Calendario Académico Duoc UC 2026 proporcionado no contiene esa información.

10. No asumir que este calendario aplica automáticamente a otros años.
